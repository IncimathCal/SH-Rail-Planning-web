# SH-Rail-Planning-web

上海轨道交通远期规划图 · 交互式网页。以 Illustrator 绘制的远期规划图（约 60 条线路、近 2000 车站）为数据来源，构建 MapLibre 地理化渲染的静态交互线网图，部署于 GitHub Pages。

## 当前状态

阶段 1（规范与骨架）完成：仓库结构、数据 schema v1、校验器与样例数据就绪。后续按《架构方案-01-Schema与目录与阶段.md》的阶段划分推进（阶段 0 标定试验 → 编辑器 → 查看器上线）。

## 目录

| 路径 | 说明 |
|---|---|
| `架构方案-01-*.md`、`讨论记录-*.md` | 实施基准与决策历史（先读架构方案） |
| `data/` | 权威数据：每线一份 `lines/l####.json`、`groups.json`（线组+换乘节点库）、`manifest.json` |
| `import/` | `svg_parse.py` 从 AI 导出 SVG 提取的线路 path |
| `tools/` | Python 离线工具链（校验、标定、加密、字形、发布） |
| `src/` | 查看器/编辑器共享前端代码 |
| `index.html` / `editor.html` | 查看器入口（发布源）/ 编辑器入口（仅本地，永不部署） |
| `docs/` | GitHub Pages 部署目录（`publish.py` 生成，勿手改） |
| `源资产/` | 用户提供的 SVG/KML 原始文件（本地保留，已 gitignore） |

## 数据纪律

本项目全部线网数据（线型、设站、站名、状态、关系）**一律由作者提供，不引用任何外部数据源**（OSM、维基、第三方数据库等一律不使用）。设站与站名纯手动录入。

## 常用命令

```bash
# 数据校验（提交前必跑；目标目录默认 data）
python tools/validate.py data

# 对样例数据跑校验
python tools/validate.py tools/fixtures/sample

# 录入数据 → 查看器渲染数据（默认输出 build/net）
python -X utf8 tools/flatten.py --data data --out build/net

# 本地开发服务（编辑器/查看器共用，替代 python -m http.server）
python -X utf8 tools/serve.py        # http://localhost:8000

# 查看器纯逻辑单测（node）
node tools/test_viewer_logic.js
```

## 本地预览（查看器）

`index.html` 以**相对路径**依次拉取 `net/lines.geojson`、`net/stops.geojson`（第一候选
`net/` 为发布快照位，取不到回退 `build/net/` 即本地 flatten 默认输出位），因此仓库根与
`docs/` 部署快照两种打开方式都通：

```bash
python -X utf8 tools/flatten.py --data data --out build/net   # ① 生成查看器数据
python -X utf8 tools/serve.py                                 # ② 起服务后打开 http://localhost:8000/index.html
```

必须经 HTTP 服务打开（`file://` 直开时浏览器禁止读取数据文件，页面会给出中文指引）。

查看器默认渲染不区分期次（所有线路纯色实线统一不透明，唯预控通道画虚线——段长与间隔相等、
圆头、颜色不变，常态基线不透明度 60%、随分期调光系数叠乘；聚焦重画时保持虚线身份；2026-11-23），
顶栏「分期」按钮四档循环可高亮选中期次
（其余半透明并隐站名）；线路列表双击行＝切换聚焦该线（点支线等效点主线）并跳转居中（四边按顶栏/
线路面板/站点面板/聚焦框动态留白，退出不回跳）；聚焦框内可导出该线 GeoJSON/KML；联络线不单独设色
——颜色由其联络的两条线决定：常态渲染为两端各取最近一条目标线色的沿线渐变（信息不全时深灰兜底，
站圈描边同取最近端线色）；聚焦时与该线接轨的联络线（connects 字段绑定）改为渐变高亮：以聚焦线色
从接入端不透明沿线渐隐至另一端为 0；聚焦高亮方式为「白色半透明遮罩」（不透明度 70%，2026-11-22
定案）——全都不动，在高亮线路和其他线路之间隔一层白罩（聚焦线路与渐变高亮联络线、出省渐隐段
重画于罩上，聚焦线恒原色不受分期调光）；设站与站名同被罩淡/隐去——其他线路的站圈、药丸在罩下
变淡、站名隐藏，聚焦线的站圈、药丸与站名在罩上完整显示（恒原色常显）；线路面板可收起
（左缘「线路」半出药丸点击展开）；站名拉近渐显统一门槛 z≥11（组站不分，
2026-11-23 用户裁定废止组 z≥10/站 z≥11 两级制）＋「站名」全局显隐开关；拉
远时线宽、站圈与站名文字随画布等比缩小
（z<11 按 2^(z−11)、无下限；z≥11 封顶为常量值）。画布为白板底：站名黑字＋白色外描边（外扩＝
字号 1/8），随缩放锚定站点不漂移；站圈描边宽度 ×0.6（2026-11-22 定）。默认无底图（零外部资源）——
测试阶段可选底图四态循环 无→OSM→高德→CARTO（2026-11-22 起，上线去留待定；CARTO＝Positron
无字版、WGS84 与数据同基准恒等直叠，瓦片 key 为用户申请的免费 key、硬编码于 viewer.js，建议在
CARTO dashboard 配 referer 限制防盗用）。瓦片 100% 不透明＋60% 白色遮罩提亮（聚焦态保持 40%——
聚焦白罩已 70%，两层叠亮会过白；2026-11-23）；高德为显示侧 GCJ02 变换对齐，导出坐标恒 WGS84。

站点符号约定：同站换乘恰 2 线画合并大圈（黑边）；≥3 条逻辑线画白底黑边「药丸」（线数按逻辑线计：
同一线组的主线与支线算一条、联络线不计；成员站圈隐去，
药丸即换乘标识，链序按最近邻贪心串联；点击药丸开组信息面板）；同站组可写可选字段 `shape: "pill"`
显式强制画药丸（不论线数——两站心不重合的平行线双线站，大圆圆心取均值、半径屏幕恒定，放大后
悬浮在两线之间，2026-11-23 定案）；换乘组可嵌套——外层组的类型是其
直属站与内层组之间的关系：外层同站时整个站画成一个换乘符号（带内层组的上级组不论线数一律画药丸），外层出闸时直属站各自画黑边圈、
内层组照常；线路出省端在查看器以线身末端
1 公里沿线渐变到透明示意（编辑器仍画线色三角指向外侧；属线路标志而非车站，不参与搜索、
悬停与点选）。
