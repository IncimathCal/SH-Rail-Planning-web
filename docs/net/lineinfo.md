  数据链：本文件随数据目录被 tools/flatten.py 原样透传进 net/（不解析进 GeoJSON），

  查看器一切线组无信息节（静默，不报错）。

  写法约定（解析器按此切分，查看器展示）：
  ① 每个线组一节：二级标题「## <线组id> <线组名>」绑定线组——id 以 groups.json 里
    lineGroups 的 id 字段为准；标题里的线组名只是给人看的，不参与绑定。

    （半/全角冒号均可），查看器按原序照收照显——未来加新键零代码改动。
  ③ 空行之后是自由正文，支持的写法：段落（空行分段、段内直接换行）、无序列表
    （- 开头行）、粗体 **文字**、斜体 *文字*、链接 [文字](网址)。
  ④ 「### 相关链接」节＝链接列表区：该节下每行一个 [文字](网址)；其他三级标题节
    会当作正文原样显示（节名留作未来扩展）。
  ⑤ 网址只支持 http://、https:// 与相对路径（javascript: 等一律被拒绝，不渲染成链接）。
  ⑥ 没写信息的线组＝查看器不显示信息节（完全无痕）。
  ⑦ 本说明注释区（首个二级标题之前的任何行）不会显示，可随意保留或删除。
