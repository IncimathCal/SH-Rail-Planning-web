# 相关链接（links.md）——手填格式模板

<!--
  本文件是格式模板（零真实内容），只说明写法；相关链接由用户手填。
  2026-11-28 起：链接从 lineinfo.md 剥离，独立放在本文件（lineinfo.md 里的
  「### 相关链接」节仍兼容旧写法照常显示，但建议逐步迁到本文件来）。
  数据链：本文件随数据目录被 tools/flatten.py 原样透传进 net/（不解析进 GeoJSON），
  查看器在线路页（信息区位置、车站列表上方）显示命中的链接；本文件不存在＝
  查看器一切线路无链接区（静默，不报错）。

  写法约定（解析器按此收，查看器展示）：
  ① 一行一条链接：- [链接文字](https://…) #l0017 #l0018——行首的 - 或 * 可省；
    一条链接后面可以打多个「#<线路id>」tag，该链接就同时挂在这些线路上。
  ② tag 绑定口径与 lineinfo.md 相同：建了组的线路打线组 id（groups.json 里
    lineGroups 的 id 字段），没建组的单线打线自身 id（lines/*.json 的 id）。
    查看器按「先组 id、组没命中再落线自身 id」解析。
  ③ 网址只支持 http://、https:// 与相对路径（javascript: 等一律被拒绝，整条不显示）。
  ④ 没打 tag 的行、纯说明文字行、markdown 标题行都不会被收；HTML 注释块
    （<!-- … -->，可跨行）内的内容整体不解析——本说明区可随意保留或删除。
-->
